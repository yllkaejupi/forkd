# forkd
A bilingual (English / Albanian) recipe discovery and cooking companion built with HTML, CSS, and Vanilla JavaScript.

## Features
- Browse and discover recipes across different categories
- Switch between English and Albanian anywhere on the site, including all recipes, ingredients and steps
- Search recipes in both languages, with forgiving spelling (works with or without ë and ç)
- Filter recipes by category, difficulty, cooking time and diet, with filters saved in the URL
- See a seasonal section that changes automatically with the time of year
- View detailed recipe information, including ingredients, instructions, and cooking times
- Follow recipes step by step in cooking mode
- Save favorites and organize recipes into personal collections
- Add ingredients to an interactive grocery list, one by one or all at once
- Mark purchased ingredients and manage shopping items
- Navigate through a responsive and user-friendly interface

## Built With
- HTML, CSS and Vanilla JavaScript (ES modules)
- `localStorage` for favorites, collections, the grocery list and language choice
- [Lucide](https://lucide.dev) icons

## Getting Started
The project uses JavaScript modules, so it needs to run on a local server (opening `index.html` directly won't work).

1. Clone the repository
2. Open the folder in VS Code
3. Start it with the **Live Server** extension (or any local server)
